How It Works

  1. Upload an MP4 you own or use a direct file link.
  2. Choose Auto Edit or 1–5 clips, a style, and optional manual captions.
  3. Preview and download MP4s selected using audio and motion.

Clip selection uses activity in the footage. Audience growth and earnings vary by creator and platform.
